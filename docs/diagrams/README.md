**Источник нормативных требований — текст глав и ADR.** Схемы дают обзор, но не заменяют таблицы прав, статусные переходы, API, ответственность по юрисдикциям. В случае неоднозначности запросить обновление соответствующего требования, а не выводить новое правило из рисунка.

## При изменениях

1. Обновить источник в `.mmd`, текстовые правила в `docs/ru/`, API и тесты, если затронуты.
2. Обновить SVG в `assets/`; SVG — статическая векторная визуализация для лёгкого HTML без тяжёлых внешних библиотек.
3. Запустить `node scripts/build-site.mjs` и `node scripts/check-docs.mjs`.
4. Проверить SVG в браузере на телефоне и в тёмной теме (у SVG светлая поверхность), отсутствие переполнений и точность текста.

Главное: `ServiceOffer` всегда относится к одному продавцу (специалисту **или** компании); наличие сотрудничества не делает компанию продавцом всех работ специалиста.
